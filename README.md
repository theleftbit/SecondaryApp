# SecondaryApp

Aplicacion nativa para iOS y Android que permite abrir mediQuo desde un unico
boton centrado.

## Funcionamiento

- Abre `https://www.mediquo.com/app` directamente en la aplicacion de mediQuo.
- Si mediQuo no esta instalada, muestra su ficha en App Store o Google Play.

## Ejecutar el proyecto

### iOS

1. Abre `ios/SecondaryApp.xcodeproj` con Xcode.
2. Selecciona un simulador de iPhone.
3. Ejecuta el esquema `SecondaryApp`.

**Requisitos:** Xcode 26 o posterior e iOS 26 como version minima.

### Android

1. Abre la carpeta `android` con Android Studio.
2. Espera a que finalice la sincronizacion de Gradle.
3. Ejecuta la configuracion `app` en un emulador o dispositivo.

**Requisitos:** Android Studio compatible con Android Gradle Plugin 9.3.1 y
Android 7.0 (API 24) como version minima.
